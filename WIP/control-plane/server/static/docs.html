Wip.Factory Control Plane

Local-first operator application for the existing Wip.Factory execution engine.

Start locally

pwsh -File tools/start-control-plane.ps1

The script builds the .NET control adapter and the Rust server, starts a demo target repository and adapter, and serves this UI on http://127.0.0.1:3000.

Security

  • The adapter binds loopback by default and requires a bearer service token.
  • Operator sessions are HttpOnly cookies with server-side CSRF validation.
  • Roles are enforced by the Rust server and independently by the adapter.
  • Core dumps and logs must be handled as operator-sensitive evidence.

Configuration

Configuration is documented in README.control-plane.md and control-plane/README.md.
