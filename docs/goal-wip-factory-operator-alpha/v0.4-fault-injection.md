## Integrity notes

- K-01 is a deterministic in-process interruption of the verification seam, not an OS `TerminateProcess`. The
  durable merge record is written before the interruption and a fresh handler over the same control root is used,
  which is the property the requirement cares about. A kill inside the `git merge` syscall itself is not covered.
- K-09/K-10 use real Windows processes and the real listener table; no fake outcome flags.
- Every factory row records the exact revised source in the test assertion, not a string in an event stream.
