### PA-01 (fail)

The failure occurred before review and before any merge:

```
worktree-failed:Failed to create worktree for session 'session-impl-work-e3962e6e'.
  git worktree add -b wip/session/session-impl-work-e3962e6e ... main
  fatal: a branch named 'wip/session/session-impl-work-e3962e6e' already exists
```

Diagnosis from the durable state and filesystem (no requirement text involved):

1. The first implementation attempt **did create** the worktree and the model produced `PassesApi/` source,
   but the agent run failed before the factory committed anything (`git status` still showed untracked `PassesApi/`;
   no feature commit existed).
2. The dispatch worker retried the implementation event three times. On every retry,
   `FactoryWorktreeProvisioner` attempted to create the same branch/worktree again and failed with
   `branch already exists`.
3. The retry path therefore replaced the original agent failure with a provisioning failure; the first failure
   category was not preserved in the durable failure record.

This is a real factory reliability defect: retries after a soft agent failure are not idempotent with respect to the
session worktree, and the first failure reason is lost. It is not a contract-digest mismatch, not a review-gate
failure, and not a merged-revision failure — those stages were never reached.
