## Consequences

1. **Phase 3 executes as Option A**: WP-3.1..3.7, including chat/tool contracts, a DeepSeek adapter, a permission-aware tool invoker, the agent loop, artifact memory, streaming (SSE), runtime integration, and a write-capable sample agent + safety tests.
2. **Plan change note (§5.5).** WP-3.6’s “read-only `RepoResearchAgent`” is superseded: the sample agent is a write-capable repository agent. The plan’s note “The sample agent must be read-only by default” no longer applies; the write path is now a first-class 1.0 capability. Phase 3 estimate 29 → **31 ED** (+2 for the write tool, worktree confinement and write-path tests); program total 144 ED + 20% contingency.
3. **Write-path constraints (non-negotiable, enforced by design and tests):**
   - Writes happen only inside the session’s isolated Git worktree, never the operator’s main working tree.
   - `workspace.write` (and `artifact.write`) permissions are enforced by the WP-3.2 tool invoker; the sample agent cannot be exposed before **G3** approves and enforces the catalog.
   - Every edit flows through the existing validation → review → approval → merge boundary. The agent cannot mark its own change passed/merged (WP-0.2 governance guard); no auto-merge and no direct push.
   - The edit tool is path-confined (traversal/symlink escapes denied), audited, and diffable; deletions require an explicit approval step.
4. **WP-3.7 abuse cases must include the write path**: escape from the worktree, traversal/symlink writes, permission denial, injection-driven deletion, and an attempt to self-approve/merge. Every case fails closed.
5. **Sequencing unchanged:** G4 (Phase 2) and G3 (permissions) precede Phase 3 acceptance. G1 does not let Phase 3 skip them.
6. **Release posture unchanged:** WIP 1.0 still requires the full Phase 4–6, security review, G5, and the post-release verification. No release is authorized by G1. Full G2 remains conditional and the Windows containment residual is unchanged.

| Prompt injection makes the agent edit hostile content inside the worktree | Medium | High | Worktree isolation, validation/approval boundary, human diff review, no auto-merge, audit artifacts, WP-3.7 tests; G5 security review covers the write path |
