The spectator type is in `WIP/Wip.Tholdem.Web/Live/SpectatorSnapshot.cs` and is produced by `LiveMatch.Snapshot()` for `/api/live/{id}`.

Direct reconstruction attempt, and the break:

1. For session seed 777, hand 1, seat 0, action index 0, stream 0, the current derivation gives `TurnSeed = 3596322178983813853`.
2. Treating that value as the session seed, `SeedDerivation.Derive(3596322178983813853, 1, 0, 0, 0) = 12346186262491958633`; `SeededDeck.Create` then starts `Qh 6h 6d Jc 7h Qd 7s 2c 2d`, which does not match the record.
3. Enumerating `candidate = 0..2000` and computing `SeedDerivation.DeriveTurnSeed(candidate, 1, 0, 0, 0)` found `candidate = 777` (the 778th value).
4. `SeedDerivation.Derive(777, 1, 0, 0, 0) = 9754104818518126180`, equal to the `seed` field in the recorded hand.
5. `SeededDeck.Create(9754104818518126180)` starts `4c Tc Js Kd 2s 2h Jd Qs Ks`; the engine's no-burn deal is seat 0 `deck[0],deck[2]` = `4c,Js`, seat 1 `deck[1],deck[3]` = `Tc,Kd`, board `deck[4..8]` = `2s 2h Jd Qs Ks`.
6. The recorded hand is `.tmp/refalsify-c-r11/play777rr/sessions/tholdem-3b14b2b53132d473/hand-00001.json`: `seed:9754104818518126180`, `holeCardsSeat0:["4c","Js"]`, `holeCardsSeat1:["Tc","Kd"]`, `board:["2s","2h","Jd","Qs","Ks"]`. The full deck is reproduced, including both opponent hole cards and the future board.

Reimplementation validation: the same PowerShell arithmetic reproduced the actual product test's output for seed 42 -- `TurnSeed 3386938122580612636`, `Derive(42,1,0,0,0) 13149409904026330690`, first nine cards `Qs Tc 4s Jd 8h 8s 8d Th 6c` -- matching `AgentInformationBoundaryTests` console output.
